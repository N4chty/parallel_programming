# ЛР3 — Геометрический центр облака точек (C#)

Задача 5 пособия «Параллельное программирование на OpenMP».
Требуется .NET SDK 8+. Аргументы после `--`: `<потоки> <N> <loop|func>`.

## Что делает программа

Генерирует детерминированно файл `points.txt` из N точек (x,y,z) в кубе [0,1)^3
и читает его обратно, затем вычисляет геометрический центр — среднее по каждой
оси — двумя способами:

- `loop`  — декомпозиция цикла: точки делятся по потокам, редукция сумм вручную;
- `func`  — функциональная декомпозиция: ветви кода = оси x, y, z.

Каждый запуск печатает центр, эталон, признак совпадения (OK) и время
параллельной фазы. Версии дают одинаковый результат; `loop` ускоряется с ростом
потоков, `func` упирается в потолок из трёх ветвей.

## Команды запуска (N = 1000000)

```powershell
cd lab3
dotnet run -- 2 1000000 loop     # Рисунок 1
dotnet run -- 4 1000000 loop     # Рисунок 2
dotnet run -- 8 1000000 loop     # Рисунок 3
dotnet run -- 2 1000000 func     # Рисунок 4
dotnet run -- 4 1000000 func     # Рисунок 5
dotnet run -- 8 1000000 func     # Рисунок 6
```

## Примечание

Готовые библиотечные редукции/линк не используются — суммирование и сведение
частичных результатов написаны вручную на Thread, согласно требованию 2
методички. Файл точек создаётся в текущей папке проекта при первом запуске.
