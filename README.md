# parallel_programming

Репозиторий по дисциплине **«Аппаратные средства телекоммуникационных систем»**
(группа 4404, осенний семестр 2026/27, преподаватель М. И. Шигабутдинов).
Лабораторные работы выполняются по задачам 1–6 пособия
«Параллельное программирование на OpenMP».

**Работу выполнил:** **Устеников К. А.**, гр. 4404
**Язык реализации:** C# (.NET)

> В пособиях задачи сформулированы для OpenMP (C/C++). В C# директив компилятора
> OpenMP нет, поэтому те же конструкции моделируются штатными средствами языка
> (`System.Threading`): команда потоков — массив `Thread` + `Start()`, неявный
> барьер — `Join()`, критическая секция — `lock`, атомарные операции —
> `Interlocked`/`Volatile`, фиксация порядка и обмен — `Monitor`,
> `BlockingCollection`, `SemaphoreSlim`, `ManualResetEventSlim`. Число потоков
> (аналог `OMP_NUM_THREADS`) и размер задачи передаются через командную строку.

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) версии 8.0 или новее.
  Проверка: `dotnet --version`.

## Структура

```
parallel_programming/
├─ lab1/            # ЛР1 — задачи 1, 2, 3
│  ├─ task1/        #   идентификация потоков (Hello World)
│  ├─ task2/        #   обработка массива, типы расписания (schedule)
│  ├─ task3/        #   обратный порядок вывода, 5 способов синхронизации
│  └─ README.md
├─ lab2/            # ЛР2 — задача 4 (перемножение матриц)
│  └─ README.md
├─ lab3/            # ЛР3 — задача 5 (добавляется по мере сдачи)
├─ lab4/            # ЛР4 — задача 6 (добавляется по мере сдачи)
├─ openmp.pdf       # методическое пособие
└─ README.md        # этот файл
```

Каждая подпапка `task*` / `lab2` — самостоятельный консольный проект C#
(свой `.csproj` + `Program.cs`), поэтому запуск идёт из своей папки командой
`dotnet run -- <аргументы>`. Аргументы после `--` передаются программе в массив
`args` — это и есть «число потоков и размер задачи через командную строку».

## Быстрый старт

```powershell
git clone https://github.com/N4chty/parallel_programming.git
cd parallel_programming
cd lab1/task1 ; dotnet run -- 8                  # задача 1
cd ../task2   ; dotnet run -- 8 16000 static     # задача 2
cd ../task3   ; dotnet run -- 8 1000 spin        # задача 3
cd ../../lab2 ; dotnet run -- 8 1000             # задача 4
```

Подробные команды по каждой задаче — в `lab1/README.md` и `lab2/README.md`.
