# ЛР4 — Функциональная декомпозиция с глобальной суммой (C#)

Задача 6 пособия «Параллельное программирование на OpenMP».
Требуется .NET SDK 8+. Аргументы после `--`: `<потоки> <N>`.

## Что делает программа

Читает из файла `points.txt` координаты N точек (x,y,z) и вычисляет скалярную
свёртку (Σx+Σy+Σz)/3N методом функциональной декомпозиции: три ветви (оси
x, y, z) распределяются по потокам и обновляют ЕДИНУЮ глобальную сумму через
критическую секцию `lock` (аналог `#pragma omp critical`). Каждый запуск
печатает результат, эталон, признак совпадения (OK) и время параллельной фазы.

В отличие от ЛР3 (задача 5), где редукция делалась разделением данных без
блокировок, здесь условие требует глобальной суммы, поэтому синхронизация
обязательна: без `lock` на переменной `global` возникает состояние гонки.

## Команды запуска (N = 1000000)

```powershell
cd lab4
dotnet run -- 2 1000000     # Рисунок 1
dotnet run -- 4 1000000     # Рисунок 2
dotnet run -- 8 1000000     # Рисунок 3
```

## Примечание

Готовые библиотечные редукции не используются — глобальная сумма и критическая
секция написаны вручную на Thread/lock, согласно требованию 2 методички. Файл
точек создаётся в текущей папке проекта при первом запуске.
