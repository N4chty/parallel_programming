# ЛР2 — Перемножение больших матриц (C#)

Задача 4 пособия «Параллельное программирование на OpenMP».
Требуется .NET SDK 8+. Аргументы после `--`: `<число_потоков> <N>`.

## Что делает программа

Перемножает две квадратные матрицы `A·B = C` размера `N×N`. Матрицы хранятся
одномерными массивами (`m[i*N+j]`), порядок обхода циклов `i → k → j` выбран ради
локальности данных (последовательное чтение строк, меньше промахов кэша).
Параллелирование — по строкам матрицы `C` (аналог `parallel for schedule(static)`):
потоки пишут в непересекающиеся диапазоны, поэтому гонок нет и блокировки не
нужны. Каждый запуск считает и последовательную, и параллельную версию, печатает
оба времени, коэффициент ускорения (`Speedup`) и проверку контрольных сумм
(`Results Match`). Генератор матриц использует фиксированное зерно, поэтому
последовательное время сопоставимо между запусками.

## Команды запуска (матрица 1000×1000)

```powershell
cd lab2
dotnet run -- 2 1000     # Рисунок 1: 2 потока
dotnet run -- 4 1000     # Рисунок 2: 4 потока
dotnet run -- 8 1000     # Рисунок 3: 8 потоков
```

Пример вывода (формат; конкретные миллисекунды зависят от машины):

```
Matrix: 1000x1000, threads=2
Sequential time: 1962.8742 ms
Parallel time:   1042.4597 ms
Speedup:         1.88
Results Match:   True
```

`Results Match: True` во всех запусках подтверждает корректность
распараллеливания; `Speedup` растёт с числом потоков, но остаётся сублинейным
(закон Амдала, накладные расходы на потоки, пропускная способность памяти).
Значения из трёх запусков заносятся в таблицу 1 отчёта.

## Примечание

Готовое умножение матриц (BLAS-обёртки, `Math.NET` и т. п.) не используется —
ядро умножения написано вручную, согласно требованию 2 методички.
